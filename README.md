# Clinic Booking – حجز مواعيد العيادة

إضافة ووردبريس (WordPress plugin) لعيادة أو مركز طبي: صفحة احترافية، حجز مواعيد أونلاين، لوحة تحكم للموظفين، وشات بوت. عربي · עברית · English، مع RTL/LTR تلقائي وتصميم متجاوب مع الموبايل.

A WordPress plugin for clinics: a professional clinic page, online appointment booking, a staff dashboard and a chatbot. Arabic, Hebrew and English with automatic RTL/LTR and a mobile-first layout.

## المميزات / Features

- **حجز ذكي:** خدمة ← طبيب ← يوم ← وقت (صباحًا / ظهرًا وعصرًا / مساءً) ← بيانات المريض.
- **منع الحجز المزدوج** بقفل على قاعدة البيانات، مع احترام مدة الخدمة والاستراحة والإجازات.
- **شاشة تأكيد** برقم الدور التقريبي ووقت الحضور المقترح.
- **أكثر من طبيب**، لكل طبيب خدماته ودوامه وإجازاته.
- **حماية من الحجوزات الوهمية:** كود تحقق بالإيميل أو واتساب، وقائمة حظر.
- **إلغاء وتعديل** عبر رابط خاص بالمريض حسب سياسة العيادة.
- **إيميل تأكيد وتذكير** مع ملف تقويم (ICS)، وواتساب رسمي اختياري (Meta Cloud API).
- **دفع مقدّم بتحويل بنكي** مع رفع إيصال تقبله العيادة أو ترفضه.
- **لوحة تحكم:** تقويم يومي/أسبوعي/شهري، قائمة مواعيد، مرضى، أطباء، خدمات، دوام، وأدوار موظفين.
- **شات بوت** يجيب من بيانات العيادة فقط، ولا يعطي تشخيصًا طبيًا ولا يخترع أسعارًا.
- النطاق محصور في المواعيد وبيانات التواصل، بلا ملفات طبية.

## التثبيت / Install

1. حمّل المجلد كاملًا كملف zip باسم `clinic-booking.zip`.
2. ووردبريس ← إضافات ← أضف جديد ← رفع إضافة ← تفعيل.
3. أنشئ صفحة وضع فيها `[clinic_page]`.
4. عدّل بيانات العيادة من **العيادة ← الإعدادات**.

الشرح الكامل والشورتكودات في [README-ar.md](README-ar.md).
